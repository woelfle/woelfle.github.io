Write about how we leverage harness engineering in the Scorea project to a degree where we dropped the usual kind of code review. Write about that the harness is more than tweaking the AI agent and its context. It is also about fitness functions that verify the output and about context data management to make necessary information available. It is also about slicing work so AI can focus on a part of the solution only and get feedback. Even AI benefits from 'shift left'. Write how the things we know from Scrum and xP show their value when we want to product value on steroids.
